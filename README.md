# Marketo360

Marketing and brand agency site for Marketo360.

Live site: https://marketo360.com

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Supabase client

## Getting Started

Install dependencies and run the dev server:

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 in your browser.

## Scripts

```bash
pnpm dev
pnpm build
pnpm start
pnpm lint
```

## Project Structure

- app/ - App Router pages and layout
- app/components/ - UI sections and shared components
- app/data/ - Static data used across pages
- public/ - Static assets

## Notes

- Metadata is defined in app/layout.tsx
- Homepage sections are composed in app/page.tsx
